Este curso es muy interesante. Son varios los comandos que hay conocer para trabajar con con git

Git es un sistema de control de versiones distribuido que permite gestionar y hacer un seguimiento de los cambios realizados durante la implementación de un sistema informático

Comandos

  • git int
  • git branch <nombre-rama>
  • git add .
